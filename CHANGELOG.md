# Changelog

All notable changes to LeaveFlow are documented here.

Format based on [Keep a Changelog](https://keepachangelog.com/).

## [1.0.0] - 2025-07-15

### Added
- JWT authentication with login and registration
- Role-based access control (employee, admin)
- Leave request CRUD with status tracking
- Admin approval workflow (approve/reject)
- Leave type management with max-day policies
- Dashboard with pending/approved/total summaries
- Landing page with hero, stats, features, and how-it-works sections
- Date formatting (Mon DD, YYYY) in all request views
- Indigo accent theme across all components
- MongoDB/Mongoose data layer
- Seed endpoint for demo data
- Responsive dark-mode UI with Tailwind CSS v4
- API routes for auth, leave requests, and leave types
